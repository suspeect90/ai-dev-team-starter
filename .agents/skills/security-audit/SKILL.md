# Security Audit

1. Identify assets, user roles, trust boundaries and privileged operations.
2. Inspect server-side authorization, tenant isolation, validation and query safety.
3. Verify secret management, uploads, third-party calls, dependencies and auditability.
4. For payments check signed webhooks, idempotency, atomic state changes and reconciliation.
5. Report evidence, severity, fixes and verification; never test production without permission.
