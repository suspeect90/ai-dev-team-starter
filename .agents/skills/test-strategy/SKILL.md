# Test Strategy

1. Start with the feature contract, invariants, permissions and failure modes.
2. Assign business logic to unit tests, integration boundaries to integration tests and key journeys to E2E.
3. Include invalid input, edge cases, concurrency and authorization.
4. Use isolated deterministic fixtures and approved test environments.
5. Report exact test commands, pass/fail/skip and untested cases.
