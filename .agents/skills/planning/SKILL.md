# Planning

1. Read the request, product brief and relevant existing code.
2. State goals, non-goals, business invariants, assumptions and decisions needed.
3. Break the task into dependent milestones with acceptance criteria.
4. Identify independent work suitable for delegation and assign exclusive write paths.
5. Specify test commands, deployment risk, rollback and approvals.
