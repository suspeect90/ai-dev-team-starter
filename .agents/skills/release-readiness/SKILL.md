# Release Readiness

1. Summarize changes and backward-compatibility implications.
2. Verify available CI, lint, types, unit, integration and E2E results.
3. Check migrations, secrets, monitoring, backups and rollback instructions.
4. Classify unresolved risks, missing evidence and required approvals.
5. Recommend go/no-go; do not deploy without explicit approval.
