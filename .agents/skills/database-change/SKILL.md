# Database Change

1. Inspect the actual schema, migrations, DB engine version, constraints and query patterns.
2. Design keys, indexes and compatibility-safe migrations.
3. Keep backfills separate from schema changes when appropriate.
4. Require human approval and rollback for destructive DDL or production migrations.
5. Test on a non-production dataset and record evidence.
