# Maintaining this repository template

GitHub templates create **copies**, not a live inheritance relationship.

- Update VERSION and CHANGELOG.md when changing agent contracts or skills.
- Run the static validator, unit tests and a real multi-agent smoke test before a major release.
- Keep compatibility and migration notes for any renames or changed agent roles.
- Never overwrite custom project instructions automatically. Compare changes and propose a pull request against each derived project if updates are needed.
- Re-review permissions, model availability and the latest official Codex documentation periodically.
